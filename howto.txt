Clone project to your local.
conduct pip install for requirements file
edit .env to define your openai_api key.
Create the following directory:

<user_home>/work/Data/Bob
Then underneath all the following directories:
Consolidated
Output
Raw
Temp

All documents that tool is working on are of '.pdf' type and under
Documents/ directory.

Running:

(First Stage):
python ./bob_tool.py --createraw --filename <file_name>
(Second Stage)
python ./bob_tool.py --consolidate --filename <file_name>
(Third Stage) : Output
python ./bob_tool.py --output --filename <file_name>

Notes:

Use --pagerange via First Stage to limit running on certain pages (E.G : 4,10 -> will run only on pages between 4 and 10)
Use --filename to limit the run on specific filename (without its extension)
Use --threads <threads_number> to use parallel threading (Recommanded value: 30)
